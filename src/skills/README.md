# 🧠 مَدِينَةُ الْمَهَارَاتِ — الإصدار 2

موديول ألعاب مهارية مستقل لمنصة «رحلتي» (أعمار 6–8). **13 لعبة × 3 مستويات**، كلها بمحرّك واحد.

## الألعاب
حُلَّهَا (منطق) • المحقق الصغير (ملاحظة) • ذاكرتي القوية • ما النمط؟ • ألغاز الصور • ألواني • أشكالي • ابنِها • الطريق الصحيح • ماذا تختار؟ • ساعد صديقك (تعاطف/تشجيع) • مغامرة المستكشف • مرسم الإبداع (جديد: تلوين، تصميم مشهد، أفكار مفتوحة).

## أنواع الأسئلة (7)
`choice` اختيار نص/صور (متعدد، مفتوح الإجابة، تسلسل أنماط، عرض مؤقت للذاكرة) • `order` ترتيب (خطوات، ألوان، أحجام) • `match` توصيل • `memory` بطاقات • `path` متاهة • `scene` تصميم مشهد • `paint` تلوين.

## الدمج
```tsx
import { SkillsHome, SkillsGamePage, SkillsLevelPage } from "../skills";
<Route path="/skills" element={<SkillsHome />} />
<Route path="/skills/:gameId" element={<SkillsGamePage />} />
<Route path="/skills/:gameId/:level" element={<SkillsLevelPage />} />
```
انسخ المجلد إلى `src/skills/` واحذف القديم كاملًا. يحتاج: `react-router-dom` + Tailwind + خط `font-arabic`. لا مكتبات إضافية. الحفظ في `localStorage` بمفتاح `skills-progress-v3`.

## النطق
- يُنطق السؤال تلقائيًا عند ظهوره، وأيقونة 🔊 بجانبه لإعادة السماع، وزر كتم في الأعلى.
- `cleanForSpeech` يحذف الإيموجي والرموز تلقائيًا؛ الصور والأشكال لا تُنطق أبدًا.
- بعض المتصفحات لا تنطق قبل أول لمسة من الطفل، وجودة العربية تتبع أصوات الجهاز.

## إضافة محتوى (بدون لمس الواجهة)
أضف سؤالًا لبنك أي لعبة في `data/content/<game>.ts`:
```ts
choice('d2_7', 'مَا لَوْنُ السَّمَاءِ؟', ['أَزْرَقُ', 'أَحْمَرُ', 'أَسْوَدُ'], 0, { explain: '...' })
vchoice('id', 'أَيُّ صُورَةٍ ...؟', [['🐱','الْقِطَّةُ'], ['🐶','الْكَلْبُ']], 0)
order('id', 'رَتِّبْ ...', [['خُطْوَةٌ أُولَى','💧'], ['خُطْوَةٌ ثَانِيَةٌ','🧼']])
```
الصور: إيموجي، أو `S('star','red')` أشكال SVG، أو `SW('#hex')` عينة لون. كل مستوى يسحب 5 أسئلة عشوائية من البنك، فكلما كبر البنك تنوّعت المحاولات. المولّدات (`data/generators/`) تصنع أسئلة لا نهائية للأنماط والألوان والأشكال والألغاز.
لعبة جديدة: ملف في `content/` ثم إضافته في `data/games.ts` فقط.

## التحقق قبل النشر
```bash
npm i -D tsx
npm run validate:skills   # يفحص التشكيل في كل النصوص، بنية الأسئلة، وقابلية حل المتاهات
```
يُنصح بمراجعة لغوية بشرية للتشكيل (خصوصًا الحالات الإعرابية) قبل الإطلاق.

## ضوابط المحتوى
لا إعلانات ولا روابط خارجية ولا عنف ولا حظ؛ الأخطاء تُقابَل بتشجيع وتلميح بعد خطأين؛ القيم إسلامية (أمانة، سلام، بسملة، رحمة بالحيوان، ترشيد الماء، استئذان الأهل). الخطاب بصيغة المذكر في الإرشادات؛ يمكن لاحقًا إضافة خيار المؤنث.
