# منصة التعلم الشاملة للأطفال

منصة محلية تفاعلية مبنية بـ React وTypeScript وVite. تضم أربعة أقسام تعليمية: **تعلم العربية، Learn English، مغامرة الأرقام، واكتشف ما حولك**. يستخدم التطبيق ملفات JSON للمحتوى وIndexedDB وlocalStorage لحفظ الملفات والتقدم والإعدادات على الجهاز.

## المتطلبات والتشغيل

- Node.js 22 أو أحدث (متطلب Capacitor 8).
- `npm install` ثم `npm run dev`.
- `npm run build` لبناء نسخة الإنتاج.
- `npm run lint` لفحص الكود.
- `npm run validate:content` لفحص بيانات محتوى العربية.

## مسارات المنصة

| المسار | الوظيفة |
|---|---|
| `/` | الصفحة الرئيسية وبطاقات الأقسام الأربعة ومقاطع التعريف |
| `/arabic` | الصفحة الرئيسية لتعلم العربية |
| `/arabic/world/letters`، `/arabic/world/harakat`، `/arabic/world/syllables`، `/arabic/world/words`، `/arabic/world/sentences`، `/arabic/world/stories` | عوالم العربية وصفحات تفاصيلها وتدريباتها |
| `/arabic/test` | الاختبار الكلي للعربية: ٣ مستويات × ١٠ أسئلة، مع حفظ النتائج وفتح متسلسل |
| `/english` | الصفحة الرئيسية لتعلم الإنجليزية |
| `/english/letters`، `/english/phonics`، `/english/words`، `/english/sentences`، `/english/stories` | عوالم الإنجليزية |
| `/english/test` | الاختبار الشامل للإنجليزية |
| `/numbers` | الصفحة الرئيسية لمغامرة الأرقام |
| `/numbers/map`، `/numbers/stage/:id`، `/numbers/learn/:n` | الخريطة والمراحل ودروس الأعداد ١–٢٠ |
| `/numbers/practice/:topic` | تدريبات الجمع والطرح والمقارنة وغيرها، ويشمل `final` الاختبار الكبير |
| `/numbers/games`، `/numbers/games/:id`، `/numbers/numberline` | ألعاب الأرقام وخط الأعداد |
| `/numbers/voice-studio` | استوديو تسجيل الأرقام (للتطوير فقط، يبقى على مساره بعد الحفظ والتحديث) |
| `/discover`، `/discover/:worldId`، `/discover/test` | صفحة اكتشف، العوالم والأنشطة، والاختبار الشامل |
| `/parent` | اختيار لوحة ولي الأمر للقسم |
| `/parent/arabic`، `/parent/english`، `/parent/numbers` | إعدادات ونتائج ولي الأمر للأقسام |
| `/voice-studio`، `/english/voice-studio`، `/discover/voice-studio` | استوديوهات العربية والإنجليزية والاكتشاف (للتطوير فقط) |
| `/parent/numbers` | لوحة ولي الأمر للأرقام، ومنها يُفتح استوديو تسجيل الأرقام أثناء التطوير |

قد تستخدم الصفحات القديمة مسارات التوافق `/world/...` للعربية. تمر صفحات ولي الأمر المحمية عبر بوابة PIN المشتركة.
بعد اجتياز سؤال التحقق، تبقى لوحة ولي الأمر مفتوحة في التبويب الحالي حتى إغلاقه، بما في ذلك عند تحديث الصفحة أثناء حفظ تسجيل صوتي.

## هيكل المشروع

```text
src/
├── app/                 المسارات، حراسة الصفحات، وغلاف التطبيق
├── pages/               القسم العربي، Hub، وصفحات ولي الأمر المشتركة
├── data/                محتوى العربية وملف تعريف العوالم
├── engine/              الصوت والتقدم ومحركات المحتوى العربي المشتركة
├── services/            ملفات الأطفال والتخزين والتقدم
├── components/          عناصر الواجهة المشتركة والأزرار والخلفيات
├── english/             بيانات ومحرك وصفحات Learn English
├── numbers/             بيانات ومحرك وصفحات مغامرة الأرقام
└── discover/             بيانات ومحرك وصفحات اكتشف ما حولك
```

تُعرّف المسارات في `src/app/routes.tsx`. صفحة Hub توجه كل بطاقة إلى الوحدة المناسبة. تحرس صفحات كل وحدة محتواها بحسب قواعد التقدم الداخلية؛ روابط العودة و`ParentButton` مشتركة بصريًا، مع إعدادات منفصلة بحسب القسم.

## تعلم العربية

المحتوى في `src/data/`: الحروف، الحركات، المقاطع، الكلمات، الجمل، القصص، وملفات الصوت والعوالم. تنقل الصفحة العربية الطفل بين هذه العوالم، وتستخدم ألعاب الدروس ومكونات القراءة والصوت المشتركة. الاختبار الكلي في `src/pages/ArabicFinalTest/` يبني الأسئلة من بيانات المنهج، ويعرض ١٠ أسئلة في كل من السهل والمتوسط والصعب. لا يفتح المستوى التالي حتى حفظ نتيجة المستوى السابق. تحفظ النتائج لكل طفل في `appState`، وتعرض نتيجة كل مستوى وشاراته ثم النتيجة من ٣٠ والنسبة والتقييم.

## Learn English

الوحدة مستقلة في `src/english/`: بيانات الحروف والأصوات والكلمات والجمل والقصص، محرك الاختبارات والصوت، الصفحات، ولوحة ولي الأمر. خلفية الإنجليزية قابلة للتغيير من `EnglishBackground` وإعدادات الصفحات. التسجيلات الإنجليزية موجودة تحت `public/audio/english/`.

## مغامرة الأرقام

الوحدة مستقلة في `src/numbers/` وتشمل الخريطة والمراحل والتعلم والتمارين والألعاب وخط الأعداد ولوحة ولي الأمر واستوديو الصوت. المحتوى والأسئلة في `data/` و`lib/questions.ts`؛ التقدم والإعدادات في `lib/progress.ts`؛ تشغيل الصوت وإيقافه في `lib/arabic.ts`؛ واجهة السؤال المشتركة في `components/Quiz.tsx`. خلفية الوحدة الحالية معرفة في `numbers-adventure.css` داخل `.numbers-page` لحصر التنسيق بها.

إعدادات ولي الأمر للأرقام تشمل شكل الأرقام (العربية/الإنجليزية)، الصوت، حجم مجموعة الأسئلة، فتح المحتوى، وإعادة المحاولة للاختبار الكبير. تحفظ بيانات الوحدة في `localStorage` بمفتاح `adad-progress-v1`. تفاصيل التحديثات الخاصة بها في [`src/numbers/README-NUMBERS-UPDATE.md`](src/numbers/README-NUMBERS-UPDATE.md).

## اكتشف ما حولك

قسم مستقل في `src/discover/` يضم العوالم والمعلومات والأنشطة وبنك أسئلة الاختبار ومحرك التقدم وإعدادات ولي الأمر. يصف [`src/discover/README.md`](src/discover/README.md) عدد العوالم ومحتواها وطريقة إضافة عالم أو سؤال. الاختبار الحالي ثلاثة مستويات متسلسلة؛ لكل مستوى ٢٥ سؤالًا، وتحفظ درجاته محليًا.

## الصوت والتقدم والحفظ

- `src/hooks/useSound.ts` و`src/engine/soundManager.ts`: صوت العربية ومكونات المنصة المشتركة، مع دعم التسجيلات والنطق الآلي حيث يدعمه المتصفح.
- `src/english/engine/soundManager.ts`: صوت Learn English وتسجيلاته.
- `src/numbers/lib/arabic.ts`: تسجيلات الأرقام أو النطق الآلي الاحتياطي، مع إيقاف الصوت الجاري قبل بدء الآخر.
- تقدم ملفات الأطفال والإنجازات العربية في IndexedDB عبر Dexie (`src/services/storage/db.ts` و`progressService.ts`).
- الأرقام لها سجل محلي منفصل، وكذلك اكتشف؛ راجع ملفات `progress.ts` و`discoverProgress.ts` لمعرفة مفاتيح الحفظ.
- حذف ملف الطفل يحذف بياناته التابعة في قاعدة البيانات. إعادة الضبط من لوحة ولي الأمر تعيد تقدم القسم المحدد وفق إعداداته.

### استوديوهات التسجيل

استوديوهات العربية والإنجليزية والأرقام والاكتشاف تستخدم واجهة تسجيل مشتركة في `src/pages/VoiceStudio/VoiceStudio.tsx`، ويُعرض لكل قسم محتواه فقط. يوفّر خادم Vite أثناء التطوير واجهات قراءة العناصر وحفظ التسجيلات وحذفها؛ لذلك تظهر الاستوديوهات في `npm run dev` فقط، ولا تتوفر في بناء الإنتاج أو PWA أو التطبيق.

تستخدم بوابة لوحة الأرقام جلسة ولي الأمر المشتركة في `src/app/parentSession.ts`. يُفتح استوديو الأرقام على المسار المستقل `/numbers/voice-studio`، كي يبقى في الاستوديو بعد حفظ التسجيل وإعادة تحميل Vite للصفحة.

عند اعتماد التسجيل يُحفظ ملف MP3 داخل `public/audio/arabic/` أو `public/audio/english/` أو `public/audio/numbers/` أو `public/audio/discover/`، ويُحدّث `src/data/audio-manifest.json`. يضم استوديو الاكتشاف أسماء العوالم والأشياء، والتعليمات، وعبارات التشجيع، وأسئلة الاختبار العربية. تُضمّن نسخة المانيفست والملفات في البناء، لذا أعد البناء بعد إضافة التسجيلات كي تصل إلى النشر أو التطبيق. العربية والاكتشاف يستخدمان محرك الصوت العربي؛ الإنجليزية والأرقام تشغّلان التسجيل المطابق للنص ثم تعودان إلى Web Speech عند عدم وجود تسجيل.

تسجيلات الأرقام القديمة المحفوظة في `localStorage` تظل خيار تشغيل احتياطيًا في المتصفح، لكنها لا تُصدَّر تلقائيًا إلى ملفات المشروع. انقلها أو أعد تسجيلها من الاستوديو إذا أردت تضمينها في إصدار الإنتاج.

### الويب وPWA والتطبيق

- `npm run build` يبني الموقع وPWA، و`npm run build:native` يبني نسخة Capacitor بدون Service Worker.
- تستخدم أزرار التنقل الثابتة المساحات الآمنة في `src/styles/platform.css` كي لا تتمدد مع ارتفاع الصفحة وتتفادى النوتش وشريط الحالة.
- بعد تسجيل أصوات جديدة، أعد بناء الويب أو نفّذ `npm run cap:sync` لتحديث ملفات التطبيق الأصلية.

## مقاطع الهوية المرئية

بطاقات الصفحة الرئيسية تشغل المقاطع عند النقر على زر الفيديو. الملفات المعتمدة:

- `public/video/LearnArabic_Intro.mp4`
- `public/video/LearnEnglish_Intro.mp4`
- `public/video/LearnNumbers_Intro.mp4`

يمكن تغيير مسار كل مقطع من بيانات الأقسام في `src/pages/Hub/HubPage.tsx`. يمكن إضافة مقطع لقسم اكتشف إلى بيانات بطاقته عند توفر الملف. يفضّل عند استبدال المقاطع استخدام MP4 بترميز H.264 وصوت AAC للحفاظ على التوافق، ومراجعة جودة الصورة والصوت بعد الضغط.

## واجهة ولي الأمر والمكونات المشتركة

`ParentButton` و`ParentHub` و`ProtectedParentRoute` عناصر مشتركة. لكل قسم لوحة وإعدادات خاصة به حتى لا تتداخل تفضيلات الأرقام مع العربية أو الإنجليزية أو اكتشف. تشمل المكونات المشتركة الأخرى ملفات الطفل والصوت وأزرار العودة والخلفيات وأدوات التقدم. تظل بيانات كل وحدة ومحركاتها ضمن مجلدها متى أمكن.

## إضافة محتوى وصيانته

- أضف محتوى العربية إلى ملفات `src/data/` مع المحافظة على المعرفات وملف الصوت الموافق.
- أضف الكلمات والقصص الإنجليزية إلى ملفات `src/english/data/` مع معرفات صوت فريدة.
- أضف أو عدّل أسئلة الأرقام في `src/numbers/lib/questions.ts` واستخدم `Quiz` المشترك حتى تبقى التغذية الراجعة والتقدم متسقين.
- أضف عوالم اكتشف وعناصرها إلى `src/discover/data/discoverData.ts`، وأسئلة الاختبار إلى `discoverQuizData.ts` مع معرف فريد وإجابة وخيارات صحيحة.
- اجعل تغييرات الوحدة محصورة فيها قدر الإمكان، ولا تغيّر مفاتيح التخزين القائمة من دون ترحيل متوافق.

## التحقق

بعد تغييرات الكود شغّل `npm run build` و`npm run lint`، وشغّل `npm run validate:content` عند تعديل بيانات العربية. راجع أيضًا يدويًا المسارات والأزرار والصوت وحفظ التقدم في القسم المتأثر، ثم تأكد من أن الأقسام الأخرى ما زالت تعمل.
