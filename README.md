# منصة التعلم الشاملة للأطفال

منصة محلية تفاعلية مبنية بـ React وTypeScript وVite. تضم أقسام تعلم العربية وLearn English ومغامرة الأرقام واكتشف ما حولك وأخلاقي الجميلة ومدينة المهارات. يستخدم التطبيق ملفات JSON وبيانات TypeScript للمحتوى وIndexedDB وlocalStorage لحفظ الملفات والتقدم والإعدادات على الجهاز.

## المتطلبات والتشغيل

- Node.js 22 أو أحدث (متطلب Capacitor 8).
- `npm install` ثم `npm run dev`.
- `npm run build` لبناء نسخة الإنتاج.
- `npm run lint` لفحص الكود.
- `npm run validate:content` لفحص بيانات محتوى العربية.

```text

├── app/                 المسارات، حراسة الصفحات، وغلاف التطبيق
├── pages/               القسم العربي، Hub، وصفحات ولي الأمر المشتركة
├── data/                محتوى العربية وملف تعريف العوالم
├── engine/              الصوت والتقدم ومحركات المحتوى العربي المشتركة
├── services/            ملفات الأطفال والتخزين والتقدم
├── components/          عناصر الواجهة المشتركة والأزرار والخلفيات
├── english/             بيانات ومحرك وصفحات Learn English
├── numbers/             بيانات ومحرك وصفحات مغامرة الأرقام
└── discover/             بيانات ومحرك وصفحات اكتشف ما حولك

تُعرّف المسارات في src/app/routes.tsx. صفحة Hub توجه كل بطاقة إلى الوحدة المناسبة. تحرس صفحات كل وحدة محتواها بحسب قواعد التقدم الداخلية؛ روابط العودة وParentButton مشتركة بصريًا، مع إعدادات منفصلة بحسب القسم.

تعلم العربية
المحتوى في src/data/: الحروف، الحركات، المقاطع، الكلمات، الجمل، القصص، وملفات الصوت والعوالم. تنقل الصفحة العربية الطفل بين هذه العوالم، وتستخدم ألعاب الدروس ومكونات القراءة والصوت المشتركة. الاختبار الكلي في src/pages/ArabicFinalTest/ يبني الأسئلة من بيانات المنهج، ويعرض ١٠ أسئلة في كل من السهل والمتوسط والصعب. لا يفتح المستوى التالي حتى حفظ نتيجة المستوى السابق. تحفظ النتائج لكل طفل في appState، وتعرض نتيجة كل مستوى وشاراته ثم النتيجة من ٣٠ والنسبة والتقييم.

Learn English
الوحدة مستقلة في src/english/: بيانات الحروف والأصوات والكلمات والجمل والقصص، محرك الاختبارات والصوت، الصفحات، ولوحة ولي الأمر. خلفية الإنجليزية قابلة للتغيير من EnglishBackground وإعدادات الصفحات. التسجيلات الإنجليزية موجودة تحت public/audio/english/.

مغامرة الأرقام
الوحدة مستقلة في src/numbers/ وتشمل الخريطة والمراحل والتعلم والتمارين والألعاب وخط الأعداد ولوحة ولي الأمر واستوديو الصوت. المحتوى والأسئلة في data/ وlib/questions.ts؛ التقدم والإعدادات في lib/progress.ts؛ تشغيل الصوت وإيقافه في lib/arabic.ts؛ واجهة السؤال المشتركة في components/Quiz.tsx. خلفية الوحدة الحالية معرفة في numbers-adventure.css داخل .numbers-page لحصر التنسيق بها.

إعدادات ولي الأمر للأرقام تشمل شكل الأرقام (العربية/الإنجليزية)، الصوت، حجم مجموعة الأسئلة، فتح المحتوى، وإعادة المحاولة للاختبار الكبير. تحفظ بيانات الوحدة في localStorage بمفتاح adad-progress-v1. تفاصيل التحديثات الخاصة بها في src/numbers/README-NUMBERS-UPDATE.md.

اكتشف ما حولك
قسم مستقل في src/discover/ يضم العوالم والمعلومات والأنشطة وبنك أسئلة الاختبار ومحرك التقدم وإعدادات ولي الأمر. يصف src/discover/README.md عدد العوالم ومحتواها وطريقة إضافة عالم أو سؤال. الاختبار الحالي ثلاثة مستويات متسلسلة؛ لكل مستوى ٢٥ سؤالًا، وتحفظ درجاته محليًا.

الصوت والتقدم والحفظ
src/hooks/useSound.ts وsrc/engine/soundManager.ts: صوت العربية ومكونات المنصة المشتركة، مع دعم التسجيلات والنطق الآلي حيث يدعمه المتصفح.

src/english/engine/soundManager.ts: صوت Learn English وتسجيلاته.

src/numbers/lib/arabic.ts: تسجيلات الأرقام أو النطق الآلي الاحتياطي، مع إيقاف الصوت الجاري قبل بدء الآخر.

تقدم ملفات الأطفال والإنجازات العربية في IndexedDB عبر Dexie (src/services/storage/db.ts وprogressService.ts).

الأرقام لها سجل محلي منفصل، وكذلك اكتشف؛ راجع ملفات progress.ts وdiscoverProgress.ts لمعرفة مفاتيح الحفظ.

حذف ملف الطفل يحذف بياناته التابعة في قاعدة البيانات. إعادة الضبط من لوحة ولي الأمر تعيد تقدم القسم المحدد وفق إعداداته.

استوديوهات التسجيل
استوديوهات العربية والإنجليزية والأرقام والاكتشاف وأخلاقي الجميلة ومدينة المهارات تستخدم واجهة تسجيل مشتركة في src/pages/VoiceStudio/VoiceStudio.tsx، ويُعرض لكل قسم محتواه فقط. يوفّر خادم Vite أثناء التطوير واجهات قراءة العناصر وحفظ التسجيلات وحذفها وتوليدها واعتمادها؛ لذلك تظهر واجهة الاستوديو الإدارية في npm run dev فقط، ولا تتوفر في بناء الإنتاج أو PWA أو التطبيق. يفتح الاستوديو من لوحة ولي الأمر.

تستخدم بوابة لوحة الأرقام جلسة ولي الأمر المشتركة في src/app/parentSession.ts. يُفتح استوديو الأرقام على المسار المستقل /numbers/voice-studio، كي يبقى في الاستوديو بعد حفظ التسجيل وإعادة تحميل Vite للصفحة.

عند اعتماد التسجيل يُحفظ ملف MP3 داخل public/audio/arabic/ أو public/audio/english/ أو public/audio/numbers/ أو public/audio/discover/ أو public/audio/islamic/ أو public/audio/skills/، ويُحدّث src/data/audio-manifest.json. يضم الاستوديو الجديد نصوص دروس أخلاقي الجميلة وأسئلتها وقصصها، ونصوص ألعاب مدينة المهارات ومستوياتها. تُضمّن نسخة المانيفست والملفات في البناء، لذا أعد البناء بعد إضافة التسجيلات كي تصل إلى النشر أو التطبيق. تستخدم أخلاقي الجميلة محرك الصوت المشترك: التسجيل المطابق للنص له الأولوية، ثم يعود إلى Web Speech عند غياب التسجيل أو فشل تشغيله.

يعرض استوديو العربية أيضًا عبارات التشجيع المشتركة للإجابة الصحيحة وإعادة المحاولة. تحفظ التسجيلات تحت public/audio/arabic/feedback/، ويبحث محرك الصوت عنها بالنص المطابق في مختلف الأقسام؛ وعند عدم وجودها أو تعذر تشغيلها يستمر النطق الآلي الاحتياطي. سؤال موضع الحرف في عالم الحروف يستخدم أسماء الحروف المعرفة والمشكولة مثل «أَيْنَ حَرْفُ الْبَاءِ فِي هَذِهِ الْكَلِمَةِ؟». نصوص المقاطع في src/data/syllables.json مشكولة، ويمكن تسجيلها من جديد عبر الاستوديو بعد إزالة تسجيلاتها السابقة.

في صفحات مواضع الكلمات يظهر الحرف المستهدف بحجم ولون أوضح داخل قوسين، وتعرض الكلمة أسفل صورتها بحجم أكبر لتسهيل القراءة.

تسجيلات الأرقام القديمة المحفوظة في localStorage تظل خيار تشغيل احتياطيًا في المتصفح، لكنها لا تُصدَّر تلقائيًا إلى ملفات المشروع. انقلها أو أعد تسجيلها من الاستوديو إذا أردت تضمينها في إصدار الإنتاج.

التوليد الآلي، الإيقاف والاستئناف
التوليد متاح في استوديوهات العربية والإنجليزية والأرقام واكتشف وأخلاقي الجميلة ومدينة المهارات. يعتمد خادم Vite معمارية دفعات متوازية متعددة المستويات لتقليل زمن الانتظار إلى أدنى حد:

دفعات من 8 عناصر لكل طلب HTTP: الواجهة ترسل 8 معرفات عناصر في الطلب الواحد بدل طلب لكل عنصر، فينخفض عدد الطلبات من N إلى N/8.

3 طلبات متوازية من الواجهة: كل طلب يعالج 8 عناصر داخليًا، فيصبح حتى 24 عنصرًا قيد التوليد الفعلي في وقت واحد.

حتى 8 عمليات edge-tts متوازية داخل الطلب: الخادم يولّد 8 عناصر في نفس الوقت باستخدام Python subprocess.

كتابة واحدة للمانيفست بعد كل دفعة: بدل الكتابة لكل عنصر، تُجمّع النتائج وتُكتب مرة واحدة بعد اكتمال الدفعة (8 عناصر).

لتقليل زمن الانتظار في الدفعات الكبيرة، يخزّن خادم Vite قائمة المحتوى المكتشفة مؤقتًا. مدة الكاش ثانيتان في الخمول و10 ثوانٍ أثناء التوليد النشط، ويُعاد استخدامها بين الطلبات المتوازية بدل مسح ملفات بيانات الأقسام ومجلدات أخلاقي الجميلة ومدينة المهارات في كل طلب. تُقرأ بيانات المانيفست من الذاكرة، وتُحدّث قائمة المحتوى المخزنة عند تغيير ملفات المصدر عبر مراقب Vite (مع تجاهل الملفات المؤقتة للمانيفست نفسه). عند تعثر طلب Edge-TTS مؤقتًا، يعيد الخادم المحاولة مرة واحدة بعد ثانيتين، مع مهلة 30 ثانية لكل عنصر.

عند نجاح أي عنصر، يُحفظ MP3 فورًا في مسار القسم، ويُعتمد سجلّه في المانيفست تلقائيًا، ويظهر في الاستوديو بحالة «معتمد». لا ينتظر الاستوديو انتهاء الدفعة كاملة للانتقال إلى العناصر التالية. الملفات القديمة المولّدة قبل تفعيل الاعتماد الآلي تُعتمد تلقائيًا عند فتح الاستوديو إذا كان محتواها ومسار MP3 صالحين.

زمن الكتابة والاستقرار: تُكتب المانيفست عبر طابور واحد متسلسل يمنع تصادم عمليات الكتابة المتوازية على Windows. الكتابة تتم مباشرة على الملف الأصلي مع إعادة محاولة تلقائية عند أقفال النظام أو مضاد الفيروسات (EPERM / EBUSY / EACCES)، بدل استخدام rename الذي يفشل على Windows عندما يمسك Vite أو مضاد الفيروسات الملف. هذا يمنع فقدان دفعات كاملة في منتصف التوليد.

الاعتماد الآلي: كل ملف يولّده Edge-TTS يُكتب في المانيفست بحالة approved مباشرة، فيدخل تشغيل المحتوى فورًا دون خطوة مراجعة يدوية. يمكن معاينة الصوت من قائمة الاستوديو، وحذف صوت عنصر بعينه ثم إعادة توليده عند الحاجة.

الإيقاف والاستئناف: زر الإيقاف يوقف أخذ عناصر جديدة وينتظر اكتمال ما يجري توليده بالتوازي ثم حفظه واعتماده. زر الاستئناف يعيد قراءة القائمة ويتجاوز العناصر المعتمدة، ليكمل الناقص أو القديم. تعرض الواجهة تقدم الدفعة والتقدم الكلي للقسم وعدد الأصوات المعتمدة والنسبة الجاهزة، مع إظهار عدد العناصر المتبقية في كل تحديث. عند تعذر عنصر بعد محاولته، يُعرض اسمه وخطؤه ويستمر التوليد للعناصر الأخرى؛ يبقى العنصر المتعذر ناقصًا كي يمكن إعادة المحاولة. زر «توليد هذا العنصر» لتوليد عنصر محدد.

يتضمن استوديو الإنجليزية أيضاً نصوص الأسئلة الفعلية التي ينتجها QuizRunner ومحرك quizEngine: أسئلة مواضع الحروف، وأسئلة الاختبار النهائي التي تتغير حسب الكلمة أو الحرف، وأسئلة فهم القصص. أضيفت عبارات التشجيع وإعادة المحاولة والتوجيهات الصوتية إلى قائمة التسجيل. معرفات عناصر أسئلة الألعاب ثابتة بحسب مصدرها؛ لذلك إذا تغير نص السؤال أو توسعت بيانات الحروف والكلمات، يظهر العنصر كناقص أو قديم ويصبح قابلاً للتسجيل اليدوي أو التوليد بالذكاء الاصطناعي. تُحدّث قائمة الاستوديو دورياً كل 15 ثانية أثناء الخمول، كما يمكن تحديثها يدوياً.

في كل استوديو يمكن اختيار ترتيب «غير المسجّل أولاً»، أو تفعيل مرشح العناصر الناقصة/القديمة/غير المعتمدة. يوضح عداد المتبقي عدد هذه العناصر، ويعمل الفرز نفسه في العربية والإنجليزية والأرقام والاكتشاف وأخلاقي الجميلة ومدينة المهارات.

أسماء الملفات بصيغة {contentId}_{field}__{textHash}.mp3، وتُحفظ في مجلد الصوت للقسم والمجموعة. يسجل المانيفست معرّف المحتوى والنص وبصمة النص والمسار والحالة والمصدر واسم صوت Edge-TTS. يعتمد مشغل المنصة ملفات الحالة approved فقط، ويعود للنطق الاحتياطي عند الغياب أو فشل تشغيل الصوت.

تتيح قائمة التوليد اختيار الصوت:

العربية: ar-SA-ZariyahNeural (زارية • سعودي أنثى — الافتراضي)، ar-SA-HamedNeural (حامد • سعودي ذكر)، ar-EG-ShakirNeural (شاكر • مصري ذكر)، ar-EG-SalmaNeural (سلمى • مصري أنثى).

الإنجليزية: en-US-AnaNeural (آنا — الافتراضي)، en-US-AriaNeural، en-GB-SoniaNeural، en-GB-RyanNeural.

الأصوات العربية تُبطأ بنسبة 10% وتُرفع طبقتها بمقدار 5Hz لتناسب الأطفال. يستخدم Edge-TTS تنسيق MP3 الذي ينتجه مباشرة، بينما التسجيل اليدوي يُرمّز داخل المتصفح بصيغة Mono و24kHz و64kbps. لا توجد خطوة ضغط صوت إضافية على الخادم.

يحتوي كل استوديو على زر حذف جميع تسجيلات القسم. يطلب تأكيدًا صريحًا قبل التنفيذ، ثم يحذف ملفات MP3 فقط من public/audio/{section}/ بما فيها الملفات غير المسجلة في المانيفست، ويزيل سجلات ذلك القسم من src/data/audio-manifest.json. لا يُحذف محتوى الدروس. لا يمكن بدء الحذف أثناء وجود توليد جارٍ، وبعد الحذف يمكن إعادة التوليد أو التسجيل من جديد.

الأقسام العربية تستخدم الصوت الافتراضي ar-SA-ZariyahNeural، بينما يستخدم استوديو الإنجليزية الصوت en-US-AnaNeural. يلزم تثبيت التبعية مرة واحدة من جذر المشروع باستخدام Python:

py -3 -m pip install -r requirements-voice.txt
npm run dev

إذا لم يكن أمر py متاحًا، ثبّت التبعية في بيئة Python الموجودة واضبط متغير البيئة EDGE_TTS_PYTHON على المسار الكامل إلى python.exe قبل تشغيل Vite. يلزم اتصال بالإنترنت للوصول إلى خدمة Edge-TTS. واجهة التوليد تعمل في خادم التطوير فقط؛ ملفات MP3 المعتمدة وسجلاتها تُضمّن في التطبيق عند إعادة البناء.

لوحة ولي الأمر للإنجليزية تحتوي على رابطين واضحين: العودة إلى صفحة الطفل على /english، والعودة إلى إعدادات ولي الأمر العامة على /parent.

أخلاقي الجميلة ومدينة المهارات
بيانات أخلاقي الجميلة موجودة في src/islamic/، وتقدّمها محفوظ محليًا بمفتاح مستقل، ويمكن تخصيصه لملف طفل باستخدام setIslamicProfile(childId). توفر صفحات القسم زرًا ثابتًا للعودة إلى الصفحة الرئيسية، وتفتح الشارات العالم المرتبط بها. بيانات مدينة المهارات في src/skills/ وتشمل 13 لعبة بثلاثة مستويات لكل لعبة، ويُبنى فهرس الاستوديو من بيانات محتوى المستويات.

الويب وPWA والتطبيق
npm run build يبني الموقع وPWA، وnpm run build:native يبني نسخة Capacitor بدون Service Worker.

تظهر لوحة ولي الأمر بعد حل سؤال الضرب، وتُمسح صلاحية الدخول عند مغادرة مسارات ولي الأمر أو إعادة تحميل التطبيق. هذا حاجز استخدام مناسب لمنع دخول الطفل بالخطأ، وليس نظام مصادقة آمنًا أمام مستخدم تقني؛ حماية لوحة إدارية على الإنترنت تحتاج مصادقة من الخادم.

أيقونات PWA وApple Touch تستخدم شعار رحلتي المشتق إلى خلفية بيضاء من public/images/Rehlati_Logo.webp. تُخدَّم مسارات SPA من public/_redirects (صيغة Netlify). يتطلب Service Worker في النشر اتصال HTTPS، عدا localhost. صفحات التطبيق وموارده الأساسية تُبنى مع PWA؛ أما الصور والتسجيلات الصوتية فتُحمّل وتُخزّن عند الاستخدام، لذلك لا يعني تثبيت PWA أن جميع ملفات الصوت أصبحت متاحة دون اتصال من أول مرة.

قبل نشر التطبيق في المتاجر، غيّر appId المؤقت com.example.kidslearning في capacitor.config.ts إلى معرّف reverse-DNS نهائي، وأنشئ مشاريع Android وiOS ووقّعها بإعدادات النشر الخاصة بالمالك. هذا المستودع لا يحتوي حاليًا مجلدي android/ وios/. لم يُضبط نطاق استضافة بعينه؛ إعداد إعادة كتابة الروابط الموجود مهيأ بصيغة Netlify.

تستخدم أزرار التنقل الثابتة المساحات الآمنة في src/styles/platform.css كي لا تتمدد مع ارتفاع الصفحة وتتفادى النوتش وشريط الحالة.

بعد تسجيل أصوات جديدة، أعد بناء الويب أو نفّذ npm run cap:sync لتحديث ملفات التطبيق الأصلية.

مقاطع الهوية المرئية
بطاقات الصفحة الرئيسية تشغل المقاطع عند النقر على زر الفيديو. الملفات المعتمدة:

public/video/LearnArabic_Intro.mp4

public/video/LearnEnglish_Intro.mp4

public/video/LearnNumbers_Intro.mp4

يمكن تغيير مسار كل مقطع من بيانات الأقسام في src/pages/Hub/HubPage.tsx. يمكن إضافة مقطع لقسم اكتشف إلى بيانات بطاقته عند توفر الملف. يفضّل عند استبدال المقاطع استخدام MP4 بترميز H.264 وصوت AAC للحفاظ على التوافق، ومراجعة جودة الصورة والصوت بعد الضغط.

واجهة ولي الأمر والمكونات المشتركة
ParentButton وParentHub وProtectedParentRoute عناصر مشتركة. لكل قسم لوحة وإعدادات خاصة به حتى لا تتداخل تفضيلات الأرقام مع العربية أو الإنجليزية أو اكتشف. تشمل المكونات المشتركة الأخرى ملفات الطفل والصوت وأزرار العودة والخلفيات وأدوات التقدم. تظل بيانات كل وحدة ومحركاتها ضمن مجلدها متى أمكن.

إضافة محتوى وصيانته
أضف محتوى العربية إلى ملفات src/data/ مع المحافظة على المعرفات وملف الصوت الموافق.

أضف الكلمات والقصص الإنجليزية إلى ملفات src/english/data/ مع معرفات صوت فريدة.

أضف أو عدّل أسئلة الأرقام في src/numbers/lib/questions.ts واستخدم Quiz المشترك حتى تبقى التغذية الراجعة والتقدم متسقين.

أضف عوالم اكتشف وعناصرها إلى src/discover/data/discoverData.ts، وأسئلة الاختبار إلى discoverQuizData.ts مع معرف فريد وإجابة وخيارات صحيحة.

اجعل تغييرات الوحدة محصورة فيها قدر الإمكان، ولا تغيّر مفاتيح التخزين القائمة من دون ترحيل متوافق.

التحقق
بعد تغييرات الكود شغّل npm run build وnpm run lint، وشغّل npm run validate:content عند تعديل بيانات العربية. راجع أيضًا يدويًا المسارات والأزرار والصوت وحفظ التقدم في القسم المتأثر، ثم تأكد من أن الأقسام الأخرى ما زالت تعمل.

عند اختبار التوليد الآلي، تحقق من:

تقدّم سريع ومتصل في الواجهة دون رجوع للخلف (العداد لا يعود إلى رقم أقل من السابق).

ظهور رسالة «المتبقي X» مع كل تحديث تقدم.

عدم ظهور أي أخطاء EPERM أو manifest write failed في تيرمينال npm run dev.

تطابق عدد الملفات المولّدة في public/audio/{section}/ مع عدد الإدخالات الجديدة في src/data/audio-manifest.json.
